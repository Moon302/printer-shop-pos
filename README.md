# printer-shop-pos
A lightweight PHP &amp; MySQL Point of Sale system for printer shops, featuring sales management, inventory tracking, billing, and customer records.

Built to help manage sales, inventory, customers, billing, and everyday shop activities through a simple interface.

## ✨ Features

- Sales and billing management
- Product and inventory management
- Customer records
- Transaction tracking
- Invoice generation
- Dashboard and sales overview

## 🛠️ Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## 🚀 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Moon302/printer-shop-pos.git
   ```

2. Move the project folder into your local server directory (e.g. `htdocs` in XAMPP).

3. Create a MySQL database using phpMyAdmin.

4. Import the project's database SQL file.

5. Configure your database connection in the project configuration file.

6. Start Apache and MySQL through XAMPP.

7. Open the project in your browser:

   ```text
   http://localhost/printer-shop-pos/
   ```

## 💻 Requirements

- PHP 7.4 or newer
- MySQL
- Apache or another PHP-compatible web server
